# 참가자 정보 입력
4. t를 눌러 채팅창을 켜고, 명령어 "/cac_register {subj} {mode} {group}" 를 입력하세요.
- {subj} : 참가자 이니셜 및 넘버를 입력합니다. (예: P001)
- {mode} : "seeg"/"fmri"/"beh" 중 하나를 입력합니다. (예: seeg)
- {group} : chasing -> chased 순서면 "A"를, chased -> chasing 순서면 "B"를 입력합니다.
(예. 참가자 넘버가 P001이고, seeg 실험이며 A 그룹인 경우 "/cac_register P001 seeg A" 입력)
